# 云雀 K-12 · 配载预演（Weight & Balance 预演工具）

面向支线航空公司放行员的浏览器内配载预演工具：在起飞前安排乘客、行李与燃油，
实时检查**重量限制**与**重心包线**——包括沿燃油消耗轨迹的全程检查，而不是只看起飞、落地两个端点。

机型「云雀 K-12」为虚构的 12 座通勤飞机，全部数据仅用于演示。

## 功能

- **机舱配载**：三排座位（每排 4 座）+ 前/后行李舱，乘客与行李可**拖拽**移动，也可点击选中后点击目标位置放置；座位被占用时自动交换。
- **航班清单**：内置一份 10 名乘客 + 7 件行李的初始清单；任何条目可卸下（拖到「未装载区」），未装载项不计入重量并给出提醒。
- **燃油计划**：两个油箱（后部副油箱先耗、机翼主油箱后耗）的载油量与预计航程耗油可调，耗油按固定顺序自动分配。
- **实时计算**：零油/起飞/落地重量、总力矩、重心，以及各阶段对应的包线前/后限。
- **重量—重心包线图**：包线随重量变化（前/后限按重量分段线性插值），画出从起飞到落地的**耗油轨迹**，越界段标红并标注首次越界点。
- **限制检查（按优先级排序）**：
  1. 结构重量限制（MZFW / MTOW / MLW）
  2. 单舱限制（行李舱载量、油箱容量）
  3. 燃油可行性（预计耗油 ≤ 机载燃油）
  4. 重心包线（沿轨迹全程检查，报告**首次越界阶段**与**可追溯的载荷贡献**）
  5. 清单完整性（未装载项提醒）
- **状态持久化**：每次调整自动保存到 `localStorage`，刷新页面恢复当前方案；「恢复初始航班」一键重置。

## 运行方式

需要 Node.js ≥ 18。

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm test           # 运行单元测试（Vitest）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览生产构建
```

## 机型数据（虚构）

| 项目 | 数值 |
| --- | --- |
| 空机重量（含机组与设备） | 4,500 lb @ 160 in |
| 座位 | 3 排 × 4 座，力臂 125 / 160 / 195 in |
| 前行李舱 | 臂 50 in，限 500 lb |
| 后行李舱 | 臂 235 in，限 450 lb |
| 后部副油箱（先耗） | 容量 900 lb @ 192 in |
| 机翼主油箱（后耗） | 容量 2,200 lb @ 155 in |
| MZFW / MLW / MTOW | 7,300 / 8,500 / 8,750 lb |
| 重心包线（重量 → 前限/后限 in） | 4,500→151/173；6,200→150/174；7,500→149/171.5；8,750→148/168.5 |

初始航班：10 名乘客（共 1,644 lb）、前行李舱 289 lb、后行李舱 304 lb、
副油箱 500 lb + 主油箱 1,450 lb、预计耗油 1,100 lb。该方案全部检查通过。

## 判定逻辑说明

- **力矩与重心**：每项载荷力矩 = 重量 × 力臂；重心 = 总力矩 ÷ 总重量。
- **耗油轨迹**：按油箱耗油顺序（副油箱 → 主油箱）逐段生成，段内按约 5 lb 步长采样；
  每个轨迹点记录重量、力矩、重心、阶段与各油箱剩余燃油。
- **包线检查**：前/后限随重量分段线性插值（超出标注范围取端点值）；沿**整条轨迹**逐点检查，
  因此「起飞、落地都合法但途中越界」也能被发现，并报告首次越界发生的阶段
  （起飞 / 巡航耗油（某油箱）/ 落地）。
- **载荷贡献追溯**：重心越界时，列出位于越界一侧、对重心拉力矩最大的载荷
  （乘客、行李、剩余燃油）；超重时按重量分组列出贡献；单舱超限时列出舱内全部物品。

## 可以试试的场景

- **超重**：把两个油箱都加满 → 起飞重量超过 MTOW 8,750 lb。
- **单舱超限**：把所有行李拖入后行李舱 → 后舱 593 lb 超过 450 lb 限制。
- **起飞即越后限**：全部行李入后舱 + 乘客尽量坐后排 + 副油箱加满 → 起飞重心越出包线后限。
- **途中越前限**：全部行李入前舱 + 乘客尽量坐前排 + 只加副油箱（900 lb）并把耗油设为 900
  → 起飞合法，但副油箱烧掉后重心前移，轨迹中途越出前限（两个端点之外的检查才有意义的情形）。

## 技术栈与结构

React 18 + TypeScript + Vite，测试用 Vitest（Node 环境，纯逻辑测试）。

```
src/
  lib/
    types.ts          # 领域模型类型
    aircraft.ts       # 虚构机型数据（空机、座位、行李舱、油箱、包线）
    manifest.ts       # 初始航班清单与默认燃油计划
    weightBalance.ts  # 力矩/重心、零油/起飞/落地重量、耗油分配
    envelope.ts       # 包线插值与单点判定
    trajectory.ts     # 耗油轨迹生成与首次越界检测
    limits.ts         # 限制评估、优先级排序、载荷贡献追溯
    *.test.ts         # 上述模块的单元测试
  state/store.ts      # useReducer 状态管理 + localStorage 持久化
  components/         # 机舱图、清单、燃油、摘要、告警、包线图
  App.tsx             # 组合与拖拽/点击交互
```

测试覆盖：力矩与重心计算、包线插值（节点/插值/钳制/边界）、耗油轨迹
（阶段顺序、单调性、端点合法但中途越界的检出）、限制优先级与贡献追溯、状态管理（交换/钳制/重置）。
