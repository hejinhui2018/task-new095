# 云雀 K-12 · 配载与跑道放行预演（Weight & Balance + Runway Performance 预演工具）

面向支线航空公司放行员的浏览器内配载预演工具：在起飞前安排乘客、行李与燃油，
实时检查**重量限制**与**重心包线**——包括沿燃油消耗轨迹的全程检查，而不是只看起飞、落地两个端点；
并进一步完成**跑道性能放行**：选定跑道/方向/道面与气温、气压高度、风、坡度、障碍物后，
按版本化性能表给出起飞滑跑、全发越障、单发越障、着陆四个阶段的限重、控制阶段与裕量，
自动生成减油/卸载/换跑道候选并校验。

机型「云雀 K-12」与其性能表均为虚构，全部数据仅用于演示。

## 功能

- **机舱配载**：三排座位（每排 4 座）+ 前/后行李舱，乘客与行李可**拖拽**移动，也可点击选中后点击目标位置放置；座位被占用时自动交换。
- **航班清单**：内置一份 10 名乘客 + 7 件行李的初始清单；任何条目可卸下（拖到「未装载区」），未装载项不计入重量并给出提醒。
- **燃油计划**：两个油箱（后部副油箱先耗、机翼主油箱后耗）的载油量与预计航程耗油可调，耗油按固定顺序自动分配。
- **实时计算**：零油/起飞/落地重量、总力矩、重心，以及各阶段对应的包线前/后限。
- **重量—重心包线图**：包线随重量变化（前/后限按重量分段线性插值），画出从起飞到落地的**耗油轨迹**，越界段标红并标注首次越界点。
- **跑道性能放行（首屏）**：
  - 选择机场、跑道、使用方向、干/湿道面，输入气温、气压高度、风速风向（自动沿跑道方位分解为逆/顺风）、坡度与障碍物（随跑道数据内置）；
  - 跑道**剖面示意图**（坡度、障碍物、越障所需梯度、TORA、风向箭头）与四阶段**距离/限重条**；
  - 按版本化内置性能表（`K12-PERF-A1`）做**气压高度 × 气温 × 重量严格多维插值**，再按
    **① 风 → ② 坡度 → ③ 道面**的规定顺序施加修正，分别反解
    **起飞滑跑 / 全发越障 / 单发越障**的起飞限重与**着陆限重**，标出控制阶段与裕量；
  - **超出表格覆盖范围、越过审定顺风边界（10 kt）、或插值盒含无审定数据空洞时明确拒绝**，
    绝不外推、不夹到边界、不伪装成有效限重；每个阶段都给出可展开的**输入来源与修正链**。
- **放行候选**：当前方案超重或受限时，自动比较「减油（逆耗油顺序）」「卸载（优先行李、再按最小重量）」
  「换跑道/反向」候选，逐个重新做配载 + 四阶段性能校验，**不得违反重心包线或落地限制**；
  按**保留业载 → 落地燃油余量 → 操作改动量**排序，不可行尝试单独列出并注明原因。
- **撤销 / 重做**：所有调整（含采用候选）可撤销重做；滑块连续拖动自动合并为一个撤销点；历史随方案持久化，**刷新恢复**。
- **限制检查（按优先级排序）**：
  1. 结构重量限制（MZFW / MTOW / MLW）
  2. 单舱限制（行李舱载量、油箱容量）
  3. 燃油可行性（预计耗油 ≤ 机载燃油）
  4. 重心包线（沿轨迹全程检查，报告**首次越界阶段**与**可追溯的载荷贡献**）
  5. 跑道性能（四阶段限重/拒绝，与燃油轨迹和当前重量实时联动）
  6. 清单完整性（未装载项提醒）
- **状态持久化**：每次调整自动保存到 `localStorage`（v2，含撤销栈）；旧 v1 数据自动迁移（补入默认跑道条件）；「恢复初始航班」一键重置。

四张表（起飞滑跑距离 ft、全发总梯度 %、单发总梯度 %、着陆距离 ft）。
修正规则：风每节 ±0.9%（距离，逆风减/顺风加）、坡度 ±5%/1%（对原始干距离加性修正）、
湿道面 ×1.15（滑跑/着陆距离）、湿道面单发限重 ×0.94、审定顺风边界 10 kt。
表中高×热×重的若干组合标注为**无审定数据**（null），查询命中即拒绝。

## 判定逻辑说明

- **力矩与重心**：每项载荷力矩 = 重量 × 力臂；重心 = 总力矩 ÷ 总重量。
- **耗油轨迹**：按油箱耗油顺序（副油箱 → 主油箱）逐段生成，段内按约 5 lb 步长采样；
  每个轨迹点记录重量、力矩、重心、阶段与各油箱剩余燃油。
- **包线检查**：前/后限随重量分段线性插值（超出标注范围取端点值）；沿**整条轨迹**逐点检查，
  因此「起飞、落地都合法但途中越界」也能被发现，并报告首次越界发生的阶段
  （起飞 / 巡航耗油（某油箱）/ 落地）。
- **载荷贡献追溯**：重心越界时，列出位于越界一侧、对重心拉力矩最大的载荷
  （乘客、行李、剩余燃油）；超重时按重量分组列出贡献；单舱超限时列出舱内全部物品。
- **性能插值与反解**：距离/梯度按气压高度 × 气温做双线性插值；限重通过沿重量轴的精确线性反解得到。
  查询坐标落在任何轴覆盖范围之外返回 `OUT_OF_RANGE`，插值盒含 null 返回 `NO_TABLE_DATA`，
  最小表列重量仍不满足返回 `NO_FEASIBLE_WEIGHT`——**只拒绝、不外推、不夹值**。
- **修正顺序（不可交换）**：距离类按 ① 风（乘原始表列距离）→ ② 坡度（对**原始**干距离加性修正；
  起飞上坡增长滑跑、着陆上坡帮助减速故符号相反）→ ③ 道面（对前两步结果整体乘湿道面系数）应用；
  限重 = 把公布可用距离除以综合乘数后反解。单发越障湿道面在反解重量上 ×0.94 折减。
  起飞与着陆均针对所选运行方向评估（逆风对两者都有利），障碍物只约束起飞越障。
- **起飞/着陆限重分离**：起飞限重 = min(滑跑, 全发, 单发)，着陆限重单独计算（含 MLW），二者互不串值。
- **候选校验**：每个候选重新跑完整 `evaluateLoad` + `evaluateRunway`，存在任何结构/重心/燃油
  error、阶段被拒绝、或起飞/落地重量超过对应限重即判无效；排序键为保留业载 ↓、落地剩油 ↓、改动量 ↑。

## 可以试试的场景

- **短湿跑道限重（首屏默认）**：湿 09、28 °C、2,040 ft、10 kt 东风（逆风）——单发越障湿道面限重
  8,225 lb，默认 TOW 8,687 lb 超 462 lb；候选面板推荐「换 27 方向」或「减油 470 lb」「卸行李 6 件」。
  把道面切到**干**，单发限重回到 MTOW 8,750 lb，即全绿——干湿对比直观。
- **顺风越界拒绝**：把风向改成 270（西风），09 方向出现顺风；风速加到 11 kt 时所选方向四阶段
  在查表前即被拒绝（>10 kt 边界，起飞与着陆同受顺风之害），减油/卸载候选不会生成，
  换反向（27 方向，变逆风）可恢复放行。
- **超表界拒绝**：气压高度拉到 6,500 ft 或气温 45 °C，四阶段全部 `OUT_OF_RANGE`，明确不给限重。
- **超重（结构）**：把两个油箱都加满 → 起飞重量超过 MTOW 8,750 lb。
- **单舱超限**：把所有行李拖入后行李舱 → 后舱 593 lb 超过 450 lb 限制。
- **起飞即越后限**：全部行李入后舱 + 乘客尽量坐后排 + 副油箱加满 → 起飞重心越出包线后限。
- **途中越前限**：全部行李入前舱 + 乘客尽量坐前排 + 只加副油箱（900 lb）并把耗油设为 900
  → 起飞合法，但副油箱烧掉后重心前移，轨迹中途越出前限（两个端点之外的检查才有意义的情形）。

## 技术栈与结构

React 18 + TypeScript + Vite，测试用 Vitest（Node 环境，纯逻辑测试）。

```
src/
  lib/
    types.ts            # 领域模型类型
    aircraft.ts         # 虚构机型数据（空机、座位、行李舱、油箱、包线）
    manifest.ts         # 初始航班清单与默认燃油计划
    weightBalance.ts    # 力矩/重心、零油/起飞/落地重量、耗油分配
    envelope.ts         # 包线插值与单点判定
    trajectory.ts       # 耗油轨迹生成与首次越界检测
    limits.ts           # 限制评估、优先级排序、载荷贡献追溯
    performanceData.ts  # 机场/跑道数据 + 版本化性能表（K12-PERF-A1）与修正规则
    interp.ts           # 严格多维插值与重量反解（超界/空洞拒绝，不外推）
    performance.ts      # 风分解、风→坡→道面修正顺序、四阶段限重/裕量/来源链
    candidates.ts       # 减油/卸载/换跑道候选生成、全量校验与排序
    *.test.ts           # 上述模块的单元测试
  state/store.ts        # useReducer + 撤销/重做历史 + v1→v2 localStorage 迁移
  components/           # 跑道剖面/距离条、候选、机舱图、清单、燃油、摘要、告警、包线图
  App.tsx               # 组合与拖拽/点击交互、性能与配载联动
```

测试覆盖（94 个用例）：

- **插值**（`interp.test.ts`）：节点值、三轴线性插值、各轴超界 `OUT_OF_RANGE` 拒绝、
  空洞 `NO_TABLE_DATA` 拒绝（含空洞旁有效盒不跨洞）、距离/梯度反解、最小重量不可行、表内不设限；
- **修正顺序与控制限重**（`performance.test.ts`）：风分量余弦分解、顺风 10 kt 边界包含/11 kt 拒绝、
  风→坡→道面有序且不可交换、反方向坡度取反、四阶段限重/控制阶段/裕量、起飞与着陆限重分离、
  超高度/超温度拒绝、审定空洞拒绝、找不到跑道致命错误、落地限制联动；
- **候选**（`candidates.test.ts`）：减油保留全部业载且逆耗油顺序、纯行李卸载、
  有效候选不违反重心/落地、换跑道枚举、排序字典序、顺风越界时减油/卸载不生成且无效尝试留痕、
  合法方案不生成候选、候选独立复算一致；
- **历史与迁移**（`store.test.ts`）：原有配载/钳制/重置用例、性能输入更新与消毒、
  undo/redo、滑块连续动作按 coalesceKey 合并、新动作清空 redo、applyPlan 独立撤销点、
  v1→v2 迁移补默认 perf、v2 恢复含历史、损坏/错误版本/非法配载回退；
- 以及原有力矩重心、包线、耗油轨迹、限制优先级与贡献追溯用例。
