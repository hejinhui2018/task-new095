# 云雀 K-12 · 配载与跑道性能预演（Weight & Balance + Takeoff/Landing Performance）

面向支线航空公司放行员的浏览器内预演工具：在起飞前安排乘客、行李与燃油，
实时检查**重量限制、重心包线（含全程耗油轨迹）与跑道性能限重**——
即使配载方案结构全绿，短湿跑道、高温高原或大顺风仍可能拒绝放行；
系统同时给出**减油 / 卸载 / 换跑道**候选方案并按操作代价排序，采用后可撤销重做。

机型「云雀 K-12」、机场与性能表全部为虚构数据，仅用于演示。

## 功能

- **机舱配载**：三排座位（每排 4 座）+ 前/后行李舱，乘客与行李可**拖拽**移动，也可点击选中后点击目标位置放置；座位被占用时自动交换。
- **航班清单**：内置一份 10 名乘客 + 7 件行李的初始清单；任何条目可卸下（拖到「未装载区」），未装载项不计入重量并给出提醒。
- **燃油计划**：两个油箱（后部副油箱先耗、机翼主油箱后耗）的载油量与预计航程耗油可调，耗油按固定顺序自动分配。
- **跑道性能放行**：
  - 选择机场 / 跑道 / 使用方向 / 干湿道面，输入外界温度、气压高度、风向风速、坡度与障碍物；
    坡度、障碍物、气压高度默认取**跑道/机场库值**并标注来源（库值 / 人工输入，可一键恢复库值）。
  - 按内置**版本化性能表**（`K12-AFM-2026.1`）对气压高度 × 温度做**双线性插值**，
    修正严格按 **风 → 坡度 → 道面** 的规定顺序逐项乘到所需距离上，界面展示每步系数与累积系数。
  - 分别给出**起飞滑跑（TORA）、全发越障、单发停车越障、着陆距离（LDA）**四类限重、
    实际重量、裕量与控制阶段（含结构 MTOW/MLW 封顶）。
  - 首屏内置**短湿跑道示例**：白山机场 17 号方向（TORA 4,000 ft、上坡、湿道面、75 ft 障碍物），
    默认航班在该条件下被单发越障限重拦下——配载全绿但不能放行的典型情形。
- **跑道剖面与距离条**：按真实比例绘制 TORA/LDA、坡度方向、障碍物（高 / 距 / 净梯度）、
  当前重量所需距离位置；所需距离超出可用距离时距离条标红并给出超出百分比。
- **候选方案**：不可放行时枚举三类调整并**全量复验**（结构重量、燃油可行性、全程重心轨迹、起飞/着陆限重）：
  1. **换跑道 / 方向**（含换机场，自动采用新机场标高与跑道库值）——业载燃油不动，优先；
  2. **减油**（优先砍最后消耗的机翼主油箱，保证落地备份油 ≥ 300 lb）；
  3. **卸载**（枚举 1–4 名乘客/行李组合，重量最贴近缺口的优先）；
  4. 纯减油不足时给出**减油 + 卸载 1 项**的混合方案。
  排序：**保留业载 ↓ → 落地燃油余量 ↓ → 操作改动数 ↑**；任何违反重心包线或落地限重的组合都不会出现。
- **撤销 / 重做**：全部配载、燃油、跑道输入与候选采用均可撤销重做（Ctrl+Z / Ctrl+Y），
  拖动滑块等连续输入自动合并为一条历史。
- **实时计算**：零油/起飞/落地重量、总力矩、重心，以及各阶段对应的包线前/后限。
- **重量—重心包线图**：包线随重量变化（前/后限按重量分段线性插值），画出从起飞到落地的**耗油轨迹**，越界段标红并标注首次越界点。
- **限制检查（按优先级排序）**：
  1. 结构重量限制（MZFW / MTOW / MLW）
  2. 跑道性能限制（表界拒绝、顺/顶/侧风边界、坡度与湿道面批准范围、四类限重超重）
  3. 单舱限制（行李舱载量、油箱容量）
  4. 燃油可行性（预计耗油 ≤ 机载燃油）
  5. 重心包线（沿轨迹全程检查，报告**首次越界阶段**与**可追溯的载荷贡献**）
  6. 清单完整性（未装载项提醒）
- **状态持久化**：每次调整自动保存到 `localStorage`（v2 键，含跑道输入），刷新恢复；
  旧版 v1（仅配载）首次启动自动**迁移**；「恢复初始航班」一键重置（可撤销）。

性能表（`src/lib/perfTables.ts`，版本 `K12-AFM-2026.1`）：

- **距离表**：起飞滑跑 / 着陆滑跑所需距离，按 气压高度（0–8,000 ft）× 温度（−10–40 °C）× 重量（6,500–8,750 lb）索引；
  基准距离含 ISA 温度修正（起飞每 °C 偏离 ISA +0.8%，着陆 +0.4%）与气压高度倍数。
- **越障表**：全发 / 单发停车爬升限重按 气压高度 × 温度 给出，高温/高原角为 `null`（无批准数据）；
  障碍物超出 35 ft 屏隐高的额外净梯度，按扣减表扣减限重，单发表 2.5% 以上无数据。
- **修正系数**：起飞 顶风 −1.0%/kt、顺风 +5.0%/kt、上坡 +7%/%、下坡 −7%/%、湿道面 ×1.15；
  着陆 顶风 −0.6%/kt、顺风 +3.0%/kt、坡度方向相反 ±5%/%、湿道面 ×1.15。
- **批准边界**：顶风 ≤ 40 kt、顺风 ≤ 10 kt、侧风 ≤ 22 kt、坡度 ≤ ±2%、湿道面仅至 35 °C / 6,000 ft。

内置机场：白山支线机场（标高 2,050 ft，17/35 短跑道 4,000 ft + 08/26 跑道 5,600 ft）、
云川高原机场（4,520 ft，02/20）、坪北机场（780 ft，12/30，7,100 ft 长跑道）。

初始航班：10 名乘客（共 1,644 lb）、前行李舱 289 lb、后行李舱 304 lb、
副油箱 500 lb + 主油箱 1,450 lb、预计耗油 1,100 lb。结构与重心全部合法。

## 判定逻辑说明

- **力矩与重心**：每项载荷力矩 = 重量 × 力臂；重心 = 总力矩 ÷ 总重量。
- **耗油轨迹**：按油箱耗油顺序（副油箱 → 主油箱）逐段生成，段内按约 5 lb 步长采样；
  每个轨迹点记录重量、力矩、重心、阶段与各油箱剩余燃油。
- **包线检查**：前/后限随重量分段线性插值（超出标注范围取端点值）；沿**整条轨迹**逐点检查，
  因此「起飞、落地都合法但途中越界」也能被发现，并报告首次越界发生的阶段。
- **性能插值与反解**：距离/爬升表只允许在标注网格内严格双线性插值；
  以可用距离（TORA/LDA）在「修正后距离—重量」曲线的表注重量范围内线性反解限重。
  **下列情形明确拒绝，绝不外推或夹到边界伪装有效**：
  - 气压高度或温度超出表格标注范围；
  - 顶/顺/侧风分量、坡度超出批准边界；湿道面超出批准的温/高范围；
  - 越障爬升表对应单元格为 `null`（无数据），或障碍物净梯度超过扣减表末档；
  - 经风/坡度/湿道面修正后，表中**最轻**重量所需距离仍超过可用距离（无可用限重）。
- **控制限重**：起飞限重 = min(滑跑, 全发越障, 单发越障, MTOW)，着陆限重 = min(着陆距离, MLW)；
  被拒绝的阶段无有效限重，整体不能放行。
- **候选复验**：每个候选都重新跑完整的配载评估与性能评估，
  因此不会出现「减油凑够了起飞限重却在巡航途中重心越界」或「满足起飞但落地超重」的方案；
  落地剩油始终 ≥ 备份油 300 lb。

## 可以试试的场景

- **短湿跑道（首屏默认）**：白山 17 号湿道面，单发越障限重约 8,080 lb < 起飞 8,687 lb——
  候选面板给出换坪北长跑道（保留全部业载）、减油+卸 1 件、卸载 4 名乘客等排序方案。
- **改风向为顺风 12 kt**：顺风超出 10 kt 批准边界，所有场长阶段直接拒绝（无候选可救，只能换跑道/等天气）。
- **温度改成 45 °C 或气压高度 9,000 ft**：超出表注上限，提示「禁止外推」并拒绝。
- **把两个油箱都加满**（在坪北长干跑道）：起飞重量超 MTOW，候选首项即为减油（业载不丢）。
- **单舱超限**：把所有行李拖入后行李舱 → 后舱 593 lb 超过 450 lb 限制。
- **起飞即越后限**：全部行李入后舱 + 乘客尽量坐后排 + 副油箱加满 → 起飞重心越出包线后限。
- **途中越前限**：全部行李入前舱 + 乘客尽量坐前排 + 只加副油箱（900 lb）并把耗油设为 900
  → 起飞合法，但副油箱烧掉后重心前移，轨迹中途越出前限。

## 技术栈与结构

React 18 + TypeScript + Vite，测试用 Vitest（Node 环境，纯逻辑测试）。

```
src/
  lib/
    types.ts               # 领域模型类型
    aircraft.ts            # 虚构机型数据（空机、座位、行李舱、油箱、包线）
    airports.ts            # 虚构机场/跑道/方向/库值坡度与障碍物
    perfTables.ts          # 版本化性能表：距离表、爬升表、越障扣减、修正系数与边界
    manifest.ts            # 初始航班清单与默认燃油计划
    interpolate.ts         # 严格二维/一维插值（超界与 null 单元格拒绝，不外推）
    weightBalance.ts       # 力矩/重心、零油/起飞/落地重量、耗油分配
    envelope.ts            # 包线插值与单点判定
    trajectory.ts          # 耗油轨迹生成与首次越界检测
    performance.ts         # 风分解、修正顺序、限重反解、控制阶段与拒绝原因
    performanceIssues.ts   # 性能报告 → 统一告警 Issue
    candidates.ts          # 候选枚举、全量复验与排序
    limits.ts              # 配载限制评估、优先级排序、载荷贡献追溯
    *.test.ts              # 上述模块的单元测试
  state/
    store.ts               # 配载 useReducer（原语）+ localStorage v1
    appStore.ts            # 应用状态（配载+性能）、撤销重做、v1→v2 迁移、v2 持久化
  components/               # 机舱图、清单、燃油、摘要、告警、包线图、
                            # 跑道输入、跑道剖面、性能限重、候选面板
  App.tsx                  # 组合、拖拽/点击交互、告警联动
```

测试覆盖（92 个用例）：严格插值（节点/中点/超界/null 角点/边界有效）、
风分量与障碍物梯度、四类限重与控制阶段、修正顺序系数连乘、
表界/风边界/坡度/湿道面/空单元格/场长不足的各类拒绝、
候选生成排序与全量复验、包线与耗油轨迹、配载限制优先级、
撤销重做与连续输入合并、v1→v2 迁移与损坏存储恢复。
